## Como eu trabalho

- **Design antes do código.** Todo site começa com um contrato de design (conceito, paleta, tipografia e roteiro das seções) aprovado antes da primeira linha.
- **Performance medida, não suposta.** Rodo Lighthouse no celular durante o projeto, não só no fim. O portfólio atual tira 98 no ar.
- **Conteúdo primeiro, efeito depois.** HTML semântico que funciona sem JavaScript; 3D e animação entram por cima e respeitam quem prefere menos movimento.
- **Fácil de manter.** Conteúdo separado do código (arquivos JSON validados no build), então dá para trocar um projeto sem mexer na cena.
- **IA como par, eu como responsável.** Uso o Claude Code no dia a dia, revisando e entendendo cada mudança, e registro decisões e aprendizados de cada projeto num segundo cérebro no Obsidian.
